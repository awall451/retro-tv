Live TV channels with ErsatzTV

Sixteen round-the-clock channels with a guide and period commercials, built from a Plex library and flipped through in Kodi like 90s cable. This page covers the server side and the one Kodi add-on that tunes in.

How it works

A Plex server holds the movies and shows (here a server shared with this Plex account)
ErsatzTV signs in with my Plex account and pulls a file only while someone watches
ErsatzTV on a home server: keeps a schedule for each channel and re-encodes to 640×480 for the CRT
Two URLs over the home network: a channel list (M3U) and a guide (XMLTV)
Kodi on the Pi, IPTV Simple Client: TV guide, channel up and down
  • Every channel follows a clock, so tuning in drops you into the middle of whatever is on, like broadcast TV.
  • Nothing is transcoded until a channel is watched. With nobody watching there is no load on the server or on the Plex owner's upload.
  • ErsatzTV runs on a server, not on the Pi, because it re-encodes everything it plays. A desktop GPU does that easily; the Pi does not, and Batocera is not a place to run services.
  • Kodi's Plex add-on (PM4K) and the live channels are independent. One browses Plex directly; the other only knows ErsatzTV's two URLs.

What you need

A machine that is always onAnything that runs containers. Here: a Linux server with an NVIDIA GPU, running k3s (single-node Kubernetes). Docker Compose works too.

Below, <server-ip> is the server's address on your home network and 8409 is ErsatzTV's port.

1. Run ErsatzTV

The image is ghcr.io/ersatztv/legacy. Releases moved there; ghcr.io/ersatztv/ersatztv stopped at v26.2.0. One image covers NVIDIA, QSV and VAAPI. This setup runs v26.11.6; pin a version rather than using latest.

Docker Compose

The same settings as the Kubernetes deployment below, in Compose form. This guide's server runs the Kubernetes version; the Compose file follows upstream's NVIDIA example and has not been run here.

services:
  ersatztv:
    image: ghcr.io/ersatztv/legacy:v26.11.6
    restart: unless-stopped
    runtime: nvidia                      # needs nvidia-container-toolkit
    environment:
      ETV_ALLOW_SHARED_PLEX_SERVERS: "1" # only for a Plex server you don't own
      TZ: Your/Timezone                  # e.g. Europe/London: guide times follow it
      NVIDIA_DRIVER_CAPABILITIES: compute,utility,video
    ports:
      - "8409:8409"
    volumes:
      - ./config:/config                 # database, settings, Plex token
      - ./media:/media                   # commercials (optional)
    tmpfs:
      - /transcode                       # short-lived stream segments

Kubernetes

What runs here, minus probes and resource limits. Two PersistentVolumeClaims sit beside it: ersatztv-config for the database and ersatztv-media for the commercials (about 4 GB used).

apiVersion: apps/v1
kind: Deployment
metadata: { name: ersatztv, namespace: ersatztv }
spec:
  replicas: 1
  strategy: { type: Recreate }        # SQLite on one volume; one pod owns the port
  selector: { matchLabels: { app: ersatztv } }
  template:
    metadata: { labels: { app: ersatztv } }
    spec:
      enableServiceLinks: false       # a Service named ersatztv would inject ERSATZTV_PORT
      runtimeClassName: nvidia
      containers:
        - name: ersatztv
          image: ghcr.io/ersatztv/legacy:v26.11.6
          env:
            - { name: ETV_ALLOW_SHARED_PLEX_SERVERS, value: "1" }
            - { name: TZ, value: "Your/Timezone" }
            - { name: NVIDIA_DRIVER_CAPABILITIES, value: "compute,utility,video" }
          ports:
            - { name: http, containerPort: 8409, hostPort: 8409 }
          resources:
            limits: { nvidia.com/gpu: 1 }
          volumeMounts:
            - { name: config, mountPath: /config }
            - { name: media, mountPath: /media }
            - { name: transcode, mountPath: /transcode }
      volumes:
        - { name: config, persistentVolumeClaim: { claimName: ersatztv-config } }
        - { name: media, persistentVolumeClaim: { claimName: ersatztv-media } }
        - { name: transcode, emptyDir: { medium: Memory, sizeLimit: 2Gi } }
  • hostPort puts ErsatzTV on the server's own LAN address without a load balancer. A NodePort would land on a port between 30000 and 32767.
  • NVIDIA_DRIVER_CAPABILITIES must include video. The default (compute,utility) leaves the encoder libraries out of the container and NVENC fails.
  • The container runs as root and writes /config. Upstream's NVIDIA example sets privileged: true; it was not needed.

Check it

curl -s -o /dev/null -w '%{http_code}\n' http://<server-ip>:8409/iptv/channels.m3u   # 200
# inside the container:
nvidia-smi                                  # lists the GPU
ffmpeg -hide_banner -encoders | grep nvenc  # lists h264_nvenc
Keep it off the internet

ErsatzTV's web page has no login, and its config folder holds a token with full access to the Plex account. Anyone on the home network can open it. Never forward a port to it or publish it through a tunnel.

2. Connect Plex

  1. Open http://<server-ip>:8409

    Media Sources → Plex → Sign in, and approve the link on plex.tv.

  2. A server you don't own is hidden by default

    Setting the environment variable ETV_ALLOW_SHARED_PLEX_SERVERS to any value makes shared servers appear. Restart the container after adding it.

  3. Switch on the libraries to use

    Media Sources → Plex → Edit Libraries. Here: Movies and TV Shows. ErsatzTV copies titles, genres, artwork and chapter marks into its own database; the video stays on Plex.

  4. Wait for the scan

    It scans one library at a time: about 30 minutes for 3,400 movies and an hour for 280 shows (12,000 episodes). A restart queues the scans again.

3. A video profile for the CRT

Settings → FFmpeg Profiles → add one, and use it on every channel. A new channel starts on the default 1080p profile, so pick this one in the channel form each time.

SettingValueWhy
Resolution640×480What the Pi sends to the Trinitron, so nothing is rescaled on the way
ScalingScale and padWidescreen sources are letterboxed, never stretched or cropped
VideoH.264 high, 1500 kbps, buffer 3000, B-frames offThe Pi 4 decodes H.264 (not AV1); plenty for 480 lines
Hardware accelerationNVIDIA (or QSV, VAAPI, none)Fast channel changes
AudioAAC, 128 kbps, stereo, 48 kHzThe TV is stereo
LoudnessNormalize (LoudNorm), target -16Commercials and programs come out at the same volume
DeinterlaceOnOld commercial captures are interlaced
Frame rateNot normalizedFilm stays 23.976 fps, ads 29.97; Kodi handled the switch cleanly

Channels use streaming mode MPEG-TS. Kodi tuned in 0.4 to 0.7 seconds after a channel change and decoded in software at about 13% of a core.

4. Commercials

The commercials are not on Plex. They are short clips from the Internet Archive, kept in a folder ErsatzTV reads as a local library.

FolderClipsArchive.org itemWhat
/media/filler/80s122commercialpack1Late 80s and early 90s ads and station bumpers
/media/filler/90s118Collectionof90sCommercials90s ads, about 30 seconds each
/media/filler/toonami92Toonami-Bumpers, toonami-promosToonami show intros and promos
  1. Download the clips into those folders

    Each item's file list is at https://archive.org/download/<item>/. Skip anything over a few minutes long: hour-long "commercial tape" uploads make poor filler.

  2. Add the folder as a library

    Media Sources → Local → Other Videos → add the path /media/filler, then scan. ErsatzTV turns each sub-folder name into a tag (80s, 90s, toonami), which is how the collections below pick the right ads for a channel.

  3. Check the shape of every clip

    Old uploads are often the wrong shape for a 4:3 screen, and a few files are reels of several promos glued together, so one show's promo plays four times in a row. Both were fixed with ffmpeg:

    # 4:3 picture boxed inside a 16:9 frame: crop the bars off
ffmpeg -i in.mp4 -vf "crop=960:720:160:0,scale=640:480,setsar=1" -c:a aac out.mp4
# 4:3 picture stretched to 16:9 ("1080p HD" uploads): squeeze it back
ffmpeg -i in.mp4 -vf "scale=640:480,setsar=1" -c:a aac out.mp4
# a reel: find the cuts (black frame + silence), then split with -ss / -to
ffmpeg -i reel.mp4 -vf blackdetect=d=0.1 -af silencedetect=d=0.2 -f null -

    To look at a hundred clips quickly, have ffmpeg tile a few frames of each into one image (-vf "fps=1/5,scale=160:-1,tile=6x1") and read the contact sheets. Clips that are widescreen by design, such as movie trailers, were left alone.

Move a clip, then empty the Trash

A file moved out of the folder is marked "file not found" but stays in its collections and keeps being scheduled. Add AND NOT state:FileNotFound to the collection, or empty the Trash in ErsatzTV.

5. Smart collections: what each channel may play

Lists → Smart Collections. A smart collection is a saved search, so it follows the Plex library as it grows. Each channel has one for its programs, and each ad pool has one.

CollectionQuery
90s commercialstype:other_video AND tag:90s
One show, in ordertype:episode AND show_title:"Star Trek: The Next Generation"
A block of showstype:episode AND NOT season_number:0 AND (show_title:futurama OR show_title:daria OR (show_title:king AND show_title:hill))
80s action moviestype:movie AND genre:action AND release_date:[19800101 TO 19891231] AND NOT genre:animation AND NOT genre:family
Family moviestype:movie AND (genre:family OR genre:children) AND release_date:[19370101 TO 20041231] AND minutes:[45 TO 400] AND NOT content_rating:R

Query rules learned the hard way

  • Test before saving. Open http://<server-ip>:8409/search?query=… with the query and compare the count with what you expect. A query that quietly matches nothing is the usual reason a show never airs.
  • A quoted phrase with "in", "the" or "of" in it matches nothing. show_title:"Ghost in the Shell" returned zero. Use a part without those words ("Stand Alone Complex"), single words joined by AND (king AND hill), or the complete title with its punctuation ("You're Under Arrest!", "Married... with Children").
  • NOT season_number:0 keeps specials out.
  • A genre guard keeps out a live-action remake that shares a title with a cartoon.
  • To drop one episode: AND NOT (show_title:"Fighting Spirit" AND season_number:2 AND episode_number:1).

6. Ad breaks

Programs start on the hour or half hour. The gap between the end of a program and the next start is filled with commercials; ErsatzTV calls this padding. A 44-minute episode is padded to 60 minutes with 16 minutes of ads. Lists → Filler Presets holds the rules.

PresetKindModeExpression
Ads, showsMid-RollPad to nearest 30 minutespoint > 240 and remaining_duration > 180 and last_mid_filler > 300
Ads, moviesMid-RollPad to nearest 30 minutespoint > 600 and remaining_duration > 600 and last_mid_filler > 900
Ads, tailTail(none)
Ads, fallbackFallback(none)

Make one set per ad pool (80s, 90s, Toonami), each pointing at that pool's smart collection.

  • Breaks can only go where the file has a chapter mark. The expression picks which marks become breaks: point is seconds into the program, remaining_duration seconds left, last_mid_filler seconds since the last break. Shows get no break in the first 4 minutes or last 3 and at most one every 5 minutes; movies none in the first or last 10 and at most one every 15.
  • Pad mode works out the total ad time to the next :00 or :30 and splits it evenly across the chosen breaks.
  • A file with no chapter marks gets all its ads in one block after it. One mid-roll preset covers both cases. For a movie that block can reach 30 minutes.
  • A schedule item takes only one pad preset, so leave Post-Roll empty when Mid-Roll is set.
  • Fallback fills any seconds left over.
Chapter marks in the wrong place drop the program

If a file has chapter marks but none passes the expression (for example, marks only at the opening and closing credits), ErsatzTV schedules the ads and leaves the program out: 30 minutes of commercials and no show. Check a show before adding it and exclude the episodes that fail. A file with no chapters at all is safe.

The check, run against ErsatzTV's SQLite database (/config/ersatztv.sqlite3, opened read-only):

import sqlite3
db = sqlite3.connect("file:/config/ersatztv.sqlite3?mode=ro", uri=True)

def secs(t):                       # "00:23:05.1230000" to seconds
    h, m, s = t.split(":")[-3:]
    return int(h.split(".")[-1]) * 3600 + int(m) * 60 + float(s)

rows = db.execute("""
  select s.SeasonNumber, em.EpisodeNumber, mv.Id, mv.Duration
    from ShowMetadata sm
    join Season s on s.ShowId = sm.ShowId
    join Episode e on e.SeasonId = s.Id
    join EpisodeMetadata em on em.EpisodeId = e.Id
    join MediaVersion mv on mv.EpisodeId = e.Id
   where sm.Title = ? and s.SeasonNumber > 0""", ("Record of Lodoss War",))
for season, episode, version, duration in rows:
    length = secs(duration)
    ends = [secs(r[0]) for r in db.execute(
        "select EndTime from MediaChapter where MediaVersionId = ? order by StartTime", (version,))]
    points = ends[:-1]             # the last chapter ends with the file
    if ends and not any(p > 240 and length - p > 180 for p in points):
        print("would be dropped: S%sE%s" % (season, episode), [round(p) for p in ends])

7. Schedules, channels and playouts

Three things per channel, made in this order in the web page. ErsatzTV's API does not cover them.

  1. Schedule (Scheduling → Schedules)

    One item is enough: Start Type Dynamic, Collection Type Smart Collection, Playout Mode One, then Mid-Roll Filler and Fallback Filler from the presets above.

    • Chronological for a single show in order.
    • Shuffle In Order for a block of shows: shows rotate at random, each show's episodes stay in order. A show with more episodes airs more often.
    • Shuffle for movies.
  2. Channel (Channels → Add Channel)

    Number, name, streaming mode MPEG-TS, and the CRT profile from step 3.

  3. Playout (Scheduling → Playouts → Add → Classic Schedule)

    Joins the channel to its schedule. ErsatzTV builds about two and a half days ahead, starting from local midnight, and extends it every day.

Channels without commercials

Leave every filler box empty on the schedule item. Movies then run back to back and start at odd times, like a premium movie channel. This is the better home for movies whose files have no chapter marks: on a channel with ads they would end with one block of up to 30 minutes. For a film series, set Playback Order to Chronological, which for movies means release order.

Programs much shorter than half an hour

A six-minute cartoon padded to 30 minutes would carry 24 minutes of ads. For those, use Playout Mode: Duration instead of a pad preset: duration 30 minutes, Tail Mode Filler, Tail Filler set to the tail preset. ErsatzTV plays items until the next one will not fit, then fills the rest of the half hour with ads. That gives about four Looney Tunes shorts and three minutes of commercials.

To mix one short-format show into a block of half-hour shows, give the schedule two items: the block with Playout Mode Multiple (count 11), then the short show with Duration 30 minutes. The short show then gets one half hour in every twelve.

9. Tune in from Kodi

Batocera 43's Kodi already contains the add-on (pvr.iptvsimple 21.10.1 and its three inputstream helpers). It ships switched off, and it cannot be installed from Kodi's repository on Batocera, so if it is missing the image is the wrong version.

  1. Enable it

    Kodi → Settings → Add-ons → My add-ons → PVR clients → IPTV Simple Client → Enable.

  2. Point it at ErsatzTV

    Configure → add a configuration:

    • General: Location = Remote path, M3U URL = http://<server-ip>:8409/iptv/channels.m3u
    • EPG: Location = Remote path, XMLTV URL = http://<server-ip>:8409/iptv/xmltv.xml
  3. Restart Kodi

    A TV entry appears on the home menu with Channels and Guide. The guide fills in within a minute.

  4. Make it behave like a TV

    Settings → Interface → Startup → Startup window = TV. Settings → PVR & Live TV → Playback → continue the last channel on startup.

After adding or renaming channels

Kodi keeps its old list. Settings → PVR & Live TV → General → Clear data, or restart Kodi.

On the Trinitron the 640×480 picture fills the tube. On a 16:9 TV it shows bars on all four sides for widescreen sources, which is expected. How the Pi's two display profiles treat Kodi is on HDMI and Trinitron.

Changing a lineup later

Edit the smart collection's query, then reset that channel's playout so the new lineup takes effect. Both can be done in the web page, or over the API. The key is in /config/api-secrets.json.

KEY=...   # from /config/api-secrets.json
curl -H "X-Etv-Api-Key: $KEY" http://<server-ip>:8409/api/collections/smart
curl -X PUT -H "X-Etv-Api-Key: $KEY" -H "Content-Type: application/json" \
     -d '{"id": 6, "name": "Toonami Shows", "query": "type:episode AND ..."}' \
     http://<server-ip>:8409/api/collections/smart/update
curl -X POST -H "X-Etv-Api-Key: $KEY" http://<server-ip>:8409/api/channels/2/playout/reset
curl -X POST -H "X-Etv-Api-Key: $KEY" http://<server-ip>:8409/api/libraries/4/scan   # rescan a library
  • A reset rebuilds the schedule from midnight, so a shuffled channel changes what it is showing right now.
  • The full list of API calls is at http://<server-ip>:8409/openapi/v1.json. It covers video profiles, smart collections, library scans and playout resets, and nothing else.

Limits and gotchas

WhatDetail
No mid-program breaks without chapter marksMost sitcom and older cartoon files have none, so their ads come in one block at the end. Adding marks means editing the files on the Plex side.
Long ad block after an unchaptered movieUp to 30 minutes. Padding movies to the nearest 15 minutes would halve it.
Bad chapter marks drop the programSee the warning in step 6. A schedule only shows two and a half days, so a clean-looking guide does not prove a show is safe; run the check on every episode.
Phrases with stop words match nothingSee the query rules in step 5.
Bigger shows dominate a shuffled blockShuffle In Order weights by episode count. A 265-episode show is half of a 500-episode channel.
Two promos for the same show can land togetherThe shuffle has no rule against it; about 2% of neighbours.
Widescreen sourcesLetterboxed inside the 4:3 frame. Many "remastered" files of 4:3 shows are cropped to widescreen; check the file, not the air date.
Two-file rips play only the first fileOld rips split into cd1 and cd2 show their combined length, but ErsatzTV streams only the first file. Once the schedule passes its end the channel shows a "failed to transcode" card until the slot is over. Keep such movies out of lineups until the files are joined.
4:3 shows inside widescreen filesSome files hold a 4:3 picture with black side bars baked in. Scaled and padded to 4:3 they show small, with bars on all four sides. A second video profile with scaling set to Crop fills the frame, but it also cuts the sides off true widescreen sources, so use it only on a channel that has none.
Checking what a file really looks likeErsatzTV can play 30 seconds of any one item through a chosen profile: /api/troubleshoot/playback.m3u8?mediaItem=<id>&ffmpegProfile=<id>&streamingMode=4&seekSeconds=420 with the API key header, then read /iptv/session/.troubleshooting/live.m3u8 with ffmpeg and -vf cropdetect. At 640×480, an active area of 640×360 is true widescreen and 480×360 is baked-in bars.
Shared GPU memoryIf other jobs use the same GPU, a channel can fail to start while one of them holds most of the memory.
No backup by defaultChannels, schedules and presets live in ErsatzTV's database in /config, not in any file you wrote. Back that folder up, or keep notes good enough to rebuild from.
VLC on some Linux distributionsNeeds its full plugin set to play MPEG-TS; mpv plays it as is.
