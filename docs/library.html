Game library

Games and box art came from a Miyoo Mini running Onion. Each system was staged in a holding folder on the SSD, then imported by script so the art could be checked and the game lists written in one pass.

1. Stage the files

Copy each Onion system folder from the backup to /userdata/temp-rom-holding/<Onion name>/ over the share (\\<pi-ip>\share\temp-rom-holding) or with rsync. Onion keeps art in an Imgs/ subfolder named after each ROM, plus a <SYS>_cache6.db file that Batocera can't use.

2. Import cartridge systems: tools/import_onion.py

python3 import_onion.py <onion_dir> <batocera_system_dir> <broken_art_dir> [--dry-run]
  • Takes the accepted file types from the system's own _info.txt, so .sfc, .smc, .md or .bin all go where they belong.
  • Moves each ROM, and its art from Imgs/<rom>.png to images/<rom>-image.png.
  • Writes a gamelist.xml entry per game: a clean name (region and revision tags removed) and the image path, so art shows without relying on filename matching.
  • Validates every PNG fully: every chunk's CRC, an end marker, and the image data inflates. Broken images go to the broken-art folder instead of being linked.

Run with --dry-run first, and stop EmulationStation while writing game lists (/etc/init.d/S31emulationstation stop, then start).

Why the full PNG check

41 SNES covers showed blank in the menu, and its log said invalid data. They were cut off at 64, 80 or 96 KB in the Miyoo backup itself: an interrupted copy. A header check passes them; decoding the whole file catches them. Across the other systems, 18 more were set aside the same way.

3. Import PlayStation discs: tools/import_onion_psx.py

  • Reads each .cue sheet and moves it together with every .bin track it lists. A game with any missing track is skipped. All 203 cue sheets referenced 948 tracks, none missing.
  • Multi-disc games get one .m3u playlist (16 games, 39 discs). The individual discs are hidden in the game list, so each game shows once; swap discs in-game with Hotkey + L3. The grouping uses everything before (Disc N), so "Red Alert (Disc 1) (Allies)" and "(Disc 2) (Soviet)" become one game.
  • Art falls back to Onion's (Track 01) image when there's no main one.

PS1 used about 105 GB as cue/bin. Converting to .chd would roughly halve that; it hasn't been done.

4. Replacing or restoring art: tools/unlink_onion_art.py

Moves imported art back to a holding folder and removes the image links, so the scraper sees those games as missing art. It only touches entries the importers wrote (path, name, image), so bundled and scraped games keep theirs. Each game list is backed up as gamelist.xml.bak-art.

This was tried and reverted: the scraped covers weren't preferred over the Miyoo ones. To restore after a scrape, stop the menu first (it can save half-finished scraper data), move scraped files aside, move the Miyoo art back, and restore each gamelist.xml.bak-art.

5. Scraping what's missing

Main menu → Scraper, source ScreenScraper with a free account, and only games missing media, which leaves the Miyoo covers alone. A full SNES pass downloads covers only for games without one, plus a logo (marquee) for every game.
