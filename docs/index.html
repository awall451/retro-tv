Batocera Pi 4: games and Plex on a Sony Trinitron

One Raspberry Pi 4 that plays retro games and a shared Plex library, switchable from the controller between a flat HDMI TV and a 4:3 Sony Trinitron. This guide records every step so the whole setup can be rebuilt from a blank SD card.

What the finished system does

  • 1,075 games across SNES, NES, Mega Drive, Game Boy, GBC, GBA and PlayStation, imported from a Miyoo Mini (Onion) backup with its box art.
  • Two display profiles, picked from the Ports menu: a 16:9 HDMI TV with a Trinitron-style CRT shader, or the real Trinitron through an HDMI-to-composite converter at 640×480, with no shaders, overscan margins and a CRT-legible menu.
  • Kodi with live 90s-style TV channels (ErsatzTV on the homelab) and on-demand Plex (PM4K), both following the active display profile.
  • Storage on a 1 TB SSD, SSH from the PC by key, and an Argon ONE case with fan control enabled.

How the pieces connect

Windows PC: this repo, the SSH key, the flash and import tools
SSH by key, file share \\<pi-ip>\share
Raspberry Pi 4, Batocera 43.1 on microSD, /userdata on the 1 TB SSD (Argon ONE M.2 case)
HDMI 0: straight to a flat TV, or through the Dingsun converter (480i composite)
Flat HDMI TV at 1080p, or the Sony Trinitron at 640×480
Kodi pulls live channels from ErsatzTV on a home server and on-demand video from the shared Plex server
